# QLaw Markdown v1.0.0 Release Notes

## 下载说明

### Windows 用户
直接运行 QLawMarkdown_v1.0.0_windows_x64.zip 解压，双击 markdown_editor.exe 即可。

> 注意：首次运行若提示「Windows 已保护你的电脑」，点击「更多信息」>「仍要运行」即可。

### Linux / macOS 用户
请运行 download_linux_macos.ps1 脚本自动下载，或手动访问：
- Linux: https://github.com/MingQiangChen/markdown_editor55/actions/workflows/build.yml
- macOS: 同上页面，点击最新一次 Build Markdown Editor 运行记录

### Web 在线体验
将 QLawMarkdown_v1.0.0_web.zip 解压，用任意静态服务器托管，或直接访问 GitHub Pages（待配置）。

## 版本信息
- **版本号**: v1.0.0
- **发布日期**: 2026-06-16
- **Flutter SDK**: 3.29.3
- **Dart SDK**: 3.7.2

## 新功能 (v1.0.0)
- 文件树面板（项目文件浏览）
- 图片插入对话框
- 可视化表格编辑器
- 任务清单交互勾选
- 查找替换增强
- 12种导出CSS模板
- 云同步（WebDAV + 本地备份）
- 数学公式 + Mermaid 图表实时预览
- 三平台 CI 自动构建

## 已知问题
- macOS 版本需手动授权运行（系统安全限制）
- Web 端 PDF 导出依赖本地浏览器打印功能
- 拼写检查仅支持英文

## 后续版本预告
